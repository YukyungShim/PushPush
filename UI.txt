1. 레퍼런스 UI 구조 및 디자인 분석
첨부된 이미지는 전형적인 80~90년대 오락실 게임을 현대적으로 재해석한 레이아웃을 취하고 있습니다.

3단 패널 레이아웃: 좌측(조작법/상태), 중앙(메인 게임 보드), 우측(글로벌 리더보드)으로 시야가 분산되지 않게 구획되어 있습니다. 이는 Supabase와 연동할 랭킹 시스템을 우측 패널에 직관적으로 노출하기에 최적화된 구조입니다.

색상 대비 (Color Contrast): 심연의 우주를 연상시키는 짙은 네이비/퍼플 그라데이션 배경을 사용하여, 정보가 표기되는 텍스트와 게임 오브젝트의 네온 색상(Cyan, Magenta, Yellow)이 극명하게 대비되도록 설계되었습니다.

시각 효과 (Glow Effect): 패널의 테두리와 활성화된 텍스트에 얇은 빛 번짐 효과를 주어 네온사인의 질감을 살렸습니다.

2. 프론트엔드(Next.js) 구현을 위한 기술적 지침
이러한 네온 테마를 웹상에서 성능 저하 없이 구현하기 위해서는 무거운 이미지 에셋을 쓰기보다 CSS 중심의 스타일링을 권장합니다.

네온 발광 효과 구현: CSS의 box-shadow와 text-shadow를 다중으로 중첩하여 구현합니다.

예시: text-shadow: 0 0 5px #fff, 0 0 10px #fff, 0 0 20px #ff00de, 0 0 40px #ff00de;

레트로 타이포그래피: Google Fonts에서 제공하는 Press Start 2P, VT323, Orbitron 등의 픽셀 아트 또는 기계적인 느낌의 무료 웹 폰트를 전역에 적용하면 아케이드 감성을 즉각적으로 살릴 수 있습니다.

게임 보드 구성: '무중력 푸시푸시'의 메인 보드는 투명도를 가진 테두리(Border)로 격자를 구성하고, 플레이어와 공은 단순한 기하학적 도형(원, 사각형)에 강한 네온 색상과 애니메이션(Pulse 효과 등)을 부여하여 표현하는 것이 효율적입니다.

3. AI 개발을 위한 UI/UX 프롬프트 추가 가이드
앞서 작성한 마크다운 문서의 기획안에 디자인 요구사항을 추가 지시할 경우, 아래와 같이 명확한 CSS/레이아웃 제약 조건을 포함시키는 것이 좋습니다.

[추가 디자인 프롬프트 템플릿]
"게임의 전반적인 UI/UX는 1980년대 레트로 아케이드 네온 스타일로 구성하십시오.

레이아웃: 데스크톱 기준 3단 구성(좌: 조작 가이드, 중앙: 게임 보드, 우: 리더보드)으로 분할하십시오.

색상 테마: 배경은 #0a0b10 계열의 짙은 색상을 사용하고, UI 텍스트와 테두리는 Cyan(#00ffff), Magenta(#ff00ff), Yellow(#ffff00)를 메인 포인트 컬러로 활용하십시오.

컴포넌트 스타일: 모든 패널과 게임 보드의 테두리에는 CSS box-shadow를 이용한 네온 글로우(Glow) 효과를 적용하고, 폰트는 픽셀 스타일 폰트를 사용하십시오.

오브젝트 디자인: 푸시푸시의 공(Ball)은 빛나는 파란색 구체로, 목적지(Target)는 깜빡이는 노란색 네온 박스로 표현하여 시각적 인지도를 높이십시오."
